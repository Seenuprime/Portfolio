# Portfolio Website

A personal portfolio site showcasing skills and projects, built with plain HTML/CSS and icon-based skill badges (Python, TensorFlow, PyTorch equivalents, OpenCV, LangChain, scikit-learn, pandas, NumPy, Git, MySQL, and more).

## Tech stack
HTML · CSS

## Run locally
Open `index.html` in a browser, or serve the folder with any static file server.
